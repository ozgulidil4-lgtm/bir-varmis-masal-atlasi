Bir Varmış — Masal Atlası
Türk masallarını yıldızlarla temsil eden interaktif bir dijital masal arşivi.Bu proje, Programlamaya Giriş dersi kapsamında HTML, CSS ve JavaScript kullanılarak hazırlanmıştır.
Proje Özellikleri
- 10 Türk masalından oluşan dijital arşiv
- Yıldızlarla tasarlanmış interaktif masal atlası
- Masal arama ve kategori filtreleme
- Yazı boyutunu değiştirme
- Önceki ve sonraki masala geçiş
- Mobil uyumlu tasarım
